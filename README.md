# Medical-Dictionary

**Inspiration**
Wouldn't it be awesome if you could have a Dictionary in your pocket.

**What it Does?**
Medical Dictionary is chatbot which answers the user query with reference to pdf file named "Medical Dictionary".

**How we built it?**
--> With reference to 'Medical Dictionary' pdf file and pdf file is mounted to Google Drive, as per user query chatbot will give response to the user.

** Libraries used**
--> Google Colab, pypdf.
